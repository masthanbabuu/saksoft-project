# AI Building Blocks Map

## 1. Multimodal input
Multimodal input lets an AI system process combinations of text, images, audio and video. Use it when customers submit parcel photographs, voice messages or scanned documents; risks include privacy exposure, misread images and higher processing cost.

## 2. Fine-tuning
Fine-tuning adapts a pretrained model using task-specific examples so it follows a desired style or performs a narrow task more consistently. Use it when prompt engineering and retrieval are insufficient; it costs training and evaluation effort and can introduce overfitting or outdated knowledge.

## 3. Multi-agent systems
A multi-agent system divides work among specialized agents, such as tracking lookup, policy explanation and claims intake. Use it when workflows need distinct tools and responsibilities; risks include coordination errors, extra latency, increased cost and unclear accountability.

## 4. Memory
Memory stores selected information across interactions so the system can use relevant context later. Use it for an ongoing support case or user-approved preferences; risks include retaining incorrect or sensitive information and using stale details.

## 5. Context management
Context management selects and organizes the instructions, conversation history and retrieved documents sent to a model. Use it to keep answers relevant and within context limits; risks include omitted evidence, token costs and misleading summaries.

## 6. AI gateways
An AI gateway provides a controlled entry point for model requests, routing, authentication, rate limits, logging and provider selection. Use it when an organization needs centralized model governance; risks include another service to operate, latency and a potential point of failure.

## 7. Skills
Skills are reusable instructions and workflows that teach an AI system how to perform a specific task with defined steps and tools. Use them for repeatable tasks such as parcel-claim intake; risks include outdated instructions, excessive permissions and unsafe tool use.
